# Kevin Powell's Completionist
Last task that finally concluded the 21 day challenge of Kevin Powell. Started this project on August 19 and finished on August 20 2024.

# Learnings
- Create humberger manually. Done mostly by the usage of <code>::before</code> & <code>::after</code> pseudo selectors.
- Usage of flexbox can be used only for specific media queries. You don't have to rely on <code>flex-wrap: wrap;</code> to do its thing.

### Header or navbar
- the header is given text-align center to ensure that the logo is centered. It is then
given position relative for the button header to be positioned at the left hand corner
of the screen.
